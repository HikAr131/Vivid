# 锐境 Vivid

> 画质常新，安心去试。

给中文玩家的显卡画质一键管理器。检测显卡 → 选游戏 → 一键换更新的 DLSS 模型 → 出问题一键还原。

**这个软件免费公开分享，不出售。**
如果你是花钱买到的，那是被人倒卖了——请找卖家退款。

## 下载

到 [Releases](../../releases) 拿最新版，解压即用，**不需要安装**。

## 它能做什么

- 扫描 Steam 游戏库，列出已经支持 DLSS 的游戏和它们当前的模型版本
- 把老版本换成你机器上已有的更新版本（比如从 2.x 的 CNN 模型换成 310.x 的 Transformer 模型，画面清晰度差别很明显）
- **换之前自动备份，随时一键还原**，还原后与原文件逐字节一致
- 你自己另外获得的 DLL 可以拖进窗口加入备选

## 它不做什么

这几条是设计上的边界，不是暂未实现：

- **不给本来不支持 DLSS 的游戏「添加」DLSS。** 做不到，任何声称能做到的都要当心
- **不提供任何 DLL 下载，也不托管任何文件。** 只管理你机器上已有的
- **不解锁你的显卡不支持的功能。** 遇到被第三方魔改过的组件会直接拒绝处理并告诉你
- **不会让你关杀毒、关反作弊，或者给游戏加任何启动参数**

## 需要什么

- Windows 10 / 11
- NVIDIA 显卡，RTX 20 系及以上
  - 更清晰的超分模型：20/30/40/50 系都能用
  - 帧生成：需要 40 系及以上
  - DLSS 5：官方仅限 50 系，本工具不做任何绕过

## 一条重要提醒

**换过文件的游戏，请不要进联机模式。** 部分反作弊会因为文件改动判定异常。
单机随便玩，出问题点「还原」即可。
